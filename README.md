# goit-js-hw-08

Homework assignment for Neoversity University. Final project: Image Gallery.
Домашнє завдання курсу JavaScript від GoIT. Фінальний проєкт: Галерея зображень.

## Task / Завдання

Image gallery with modal window powered by basicLightbox library.
Галерея зображень з модальним вікном на основі бібліотеки basicLightbox.

- Gallery is dynamically created from the images array in JS / Галерея динамічно створюється з масиву images у JS
- Event delegation is used for click handling on gallery items / Для обробки кліків на елементи галереї використовується делегування подій
- On image click a modal window opens with the full-size version of the image / При кліку на зображення відкривається модальне вікно з повнорозмірною версією
- Clicking between gallery items does nothing / Клік між елементами галереї нічого не робить
